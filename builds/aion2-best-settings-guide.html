🖥️ Monitor and Refresh Rate

Before touching in-game settings, verify your monitor is actually running at its maximum refresh rate. Windows does not always default to this.

  1. Right-click the desktop and go to Display Settings.
  2. Scroll down and click Advanced display.
  3. Under "Choose a refresh rate," set it to the maximum your monitor supports.

Sol runs a 144Hz MSI gaming monitor. The higher your refresh rate, the more responsive the screen - you see and react to things faster. This is one of the biggest free advantages in PvP and it costs nothing.

🖥️ Check this first. If your monitor is capable of 144Hz but Windows has it set to 60Hz, you are playing at a significant disadvantage before AION 2 even opens. Full setup details are on the website.

💥 Damage Numbers

This one is a preference, but Sol strongly recommends turning damage numbers off - and here is why.

When damage numbers are off, AION 2 plays like a fighting game. You watch your character, your positioning, and your opponent's animations - not a wall of floating numbers. With them on at high or ultra effects quality, a multi-hit combo spawns 12+ separate floating numbers simultaneously. That is extra CPU overhead and it is pure screen clutter.

💥 Sol's recommendation: Turn off damage numbers. Combined with Effects Quality on Normal and Post-Processing on Very Low, the screen becomes noticeably cleaner and combat reads more like a fighting game than a number simulator. If you do want them, consolidated or side-floating damage would be ideal - hopefully Ncsoft adjusts this in a future patch.

🎯 Target Scanning

This is one of the most impactful PvP settings in the game and most players never configure it. Target scanning controls what your Tab key prioritizes when selecting enemies.

Sol's Priority Ranking Setup

Set scan mode to Front of Camera, then configure the priority ranking as follows:

  1. Hostile Players - top priority
  2. Players Attacking Me - second
  3. Targets Already Hit - third

Everything below those three is lower priority and largely irrelevant in competitive play. As long as those three are at the top, your tab-targeting logic will match Sol's setup.

Closest First (Advanced)

After setting up the priority ranking above, Sol also changes the scan mode to Closest First. When combined with the priority ranking already configured, this still respects hostile players first and selects the closest one when you tab. The priority ranking locks the targeting logic - Closest First then applies within that constraint.

🎯 Order matters. Set up the priority ranking first, then switch to Closest First. If you skip the ranking step, Closest First will just tab to the nearest anything, which is useless in large-scale. The priority ranking has to be in place for Closest First to behave like Sol's setup. If this changes in a future patch, revert to Priority Ranking mode only.

⌨️ Hotkeys

Sol's specific keybinds are personal to his playstyle, but several hotkey categories are universal must-haves regardless of class.

Must-Configure Keys
  • Flight Up and Flight Down - bind these. Flying without dedicated up/down keys is clunky and will get you killed in abyss fights.
  • Combat Analysis - this brings up the in-game DPS meter. Know where this is bound.
  • Marker Keys (Numpad) - Sol uses the numpad for applying target markers. If you have extra mouse buttons, those work too. Marking targets is very important for callouts in group PvP. Setting up mark keys is essential if you lead calls.
DPS Meters

The in-game meter only shows your own DPS. Sol recommends NotMeter as an external DPS meter - it shows you other players' DPS, which matters both for improving your own output and for identifying weak links during Transcendence content where one person's low DPS can fail the whole group.

📊 NotMeter: Sol has not seen anyone banned for using it and multiple streamers use it openly. That said, use it at your own discretion - any third-party tool carries inherent risk. The link will be in the video description.
Menu Keys - Clean Up Your Layout

In the menu key settings, remove anything bound to letters you are likely to fat-finger during normal gameplay. Sol removes bindings from G, H, and Y because accidentally hitting those keys in the middle of combat is a real problem. If a key is near your main action cluster and you would not intentionally press it, unbind it.

Looting settings are mostly default - nothing critical there. The one setting worth configuring is Auto Use HP Condition.

🔊 Audio Settings

Sol uses PC (Speaker) mode for audio output, not Headphones mode. The reason: the range between minimum and maximum volume is wider in PC mode, which gives finer volume control when mixing with an external app.

He mixes all audio through SteelSeries GG, which separates game audio, Discord chat, mic, and media into individual channels. The rough mix Sol uses:

  • Discord chat - slightly louder than game audio (you need to hear calls clearly)
  • Game audio - mid level
  • Media / music - around 48%, lower than Discord and roughly equal to game audio

If you do not use an external audio mixer, the Headphone mode is the better default for most players. SteelSeries GG is free - Sol's game audio preset is equalized based on AION 1's audio profile as a starting point.

🎧 SteelSeries GG: Free software that gives you per-application volume channels (game, Discord, media, mic) with per-channel EQ. If you are mixing music or Discord chat during streams or long sessions, this is worth setting up. Sol's AION 1-based EQ preset for the game channel will be linked in the description.

🖱️ Mouse and Hardware

Sol uses a Razer HyperSpeed wireless mouse with Razer Synapse for macro management. The key insight is that AION 2 requires a lot of button presses - especially for animation-cancel rotations - and concentrating those presses on your mouse is easier on your hands and faster in execution than alternating between keyboard and mouse constantly.

Sol's approach: the HyperSpeed extra button is bound to the R key on the keyboard. That lets him execute his main DPS rotation (Judgment on R + Pummel macro on right click) entirely from the mouse with his thumb and trigger finger - no keyboard hand switching mid-combo.

🖱️ If you play 10+ hours a day, this matters. Repetitive strain from alternating keyboard-mouse across high-APM rotations is real. Consolidating your main combo to two mouse buttons is both faster and easier on your hands long term. Full setup specs are on the website.

📁 Sol's UI File (Download)

Sol's exact UI layout is available as a file you can import directly into AION 2. This gives you his full HUD configuration: skill bar positions, minimap, chat panels, and everything else.

How to Import the UI File
  1. Download the UI file from this page (link below when available).
  2. Open File Explorer and navigate to C:\Users\[YourUsername]\
  3. If you do not see the AppData folder, go to the View menu and enable Show hidden items.
  4. Navigate to: AppData\Local\AION2\AION2_Steam\
  5. Find your User HUD folder. If it does not exist, create it - it means you have not yet saved a custom UI in-game. Log in once and adjust any setting to generate the folder.
  6. Place the downloaded file into the User HUD folder.
  7. Launch AION 2 and load the UI profile in your interface settings.
