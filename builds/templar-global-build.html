⌨️ Templar Macro Meta - The Holy Trinity

The meta Templar setup is built on the Holy Trinity: Judgment Punishment Pummel - all three taken to Lv20. With max Judgment, Punishment, and Pummel, you can run the BIS Macro Setup: animation-cancel Judgment into Pummel for maximum sustained DPS, re-prioritizing Punishment the moment it is off cooldown.

🩸 Holy Trinity (BIS core): Judgment Lv20 + Punishment Lv20 + Pummel Lv20. This is the damage backbone every Templar meta build is built around.
BIS Macro Setup - Hotkeys
  • Left Click - Quick Slot 1
  • Right Click - In-Game Macro (Quick Slot 4)
  • C - Quick Slot 2
  • R - Judgment (Razer macro key)
  • Thumb - HyperSpeed → R, ~10 presses/sec
Macro Chains
  • Right Click (PvX): Doom Shield → Annihilate → Debilitating Smash → Pummel
  • Right Click (PvE): Annihilate → Debilitating Smash → Flash Rampage → Pummel
  • Thumb (R): Judgment → Shield Smite → Warding Strike → Doom Shield
⚙️ How the in-game macro works: it activates off the first skill and runs the chain by priority (0 → 1 → 2 → 3), only firing a skill if it is available or procced. So a PvX macro that reads Doom Shield → Annihilate → Debilitating Smash → Pummel becomes a Pummel spam when nothing is procced, and auto-weaves Annihilate (on knockdown) and Debilitating Smash (on proc) when they light up. For the complete macro breakdown see the Macro Guide.
🔀 Builds are flexible: the Holy Trinity is the meta core, but alternative builds can be created around it - the alternate below is one example.

Alternate: Annihilate Lv20 (AOE Knockdown)

An alternate to the pure Holy Trinity setup takes Annihilate to Lv20. At max level, its Changes to AoE Skill specialization turns Annihilate into an AOE Knockdown - huge for crowd control in rifts, the abyss, and grouped PvE, where locking down multiple targets at once is worth more than a sliver of single-target sustain. Pair it with the -10s cooldown and +100% damage vs Incapacitated Immunity specs (see the Annihilate card above) for a control-focused variant.

📊 Lv45 vs Lv50 - Quick Reference

Same presets, two slot budgets. At Lv45 you run without the two stigmas listed as "removed" for that profile; at Lv50 you add them back.

  • PvX: Lv45 = full layout minus Second Skin + Executing Blade · Lv50 = both back in.
  • PvP (solo): Lv45 = minus Second Skin + Empyrean Lord · Lv50 = both back in.
  • PvP (group): run Comrade in Arms over Nezekan Shield at either level.
  • PvE (dungeons): Lv45 = minus Doom Shield + Nezekan Shield · Lv50 = both back in.
  • PvE (solo): run without Comrade in Arms + Taunt at either level.

📈 Stigma Leveling Priority (Breakpoints)

How you level your stigmas matters as much as which ones you slot. The whole system is driven by breakpoint value - each level milestone on a stigma is worth more or less depending on the game mode, so you chase the breakpoints that pay off for how you are playing.

🔑 The rule: unlock breadth first, then depth by value. Get all 4 stigmas to Lv1 for a game mode before deep-leveling any single one. Then push your most valuable ones to Lv5. Past Lv5, every jump (Lv10 → Lv15 → Lv20 → Lv25) is decided by which breakpoint gives the most value for that mode.

Step 1 - Unlock all 4 (Lv1)

Before anything else, take all four stigmas for the game mode to Lv1. Breadth beats early depth - you want every tool online first.

Step 2 - First pushes to Lv5

Now take your most beneficial stigmas to Lv5, in this order:

  1. Lv5 - Empyrean Lord or Executing Blade (whichever fits your mode - see below).
  2. Lv5 - Battlefield Banner.

Step 3 - Chase breakpoints (Lv10+)

After Lv5, leveling is purely about the value of each breakpoint on your best stigmas. Prioritize in this order, following whichever tags match how you play:

  • Lv10 - Empyrean Lord · PvE Prio
  • Lv10 - Executing Blade · 1v1 PvP Prio
  • Lv10 + Lv15 - Battlefield Banner · PvX Prio
  • Lv15 - Doom Shield · PvX Prio
  • Lv15 - Nezekan Shield · PvX Prio
  • Lv20 - Doom Shield · PvP Prio
  • Lv20 - Empyrean Lord · PvP Prio
  • Lv20 - Comrade in Arms · PvX Prio
  • Lv25 - Executing Blade · 1v1 PvP Prio
  • Lv25 - Doom Shield · PvX Prio
  • Lv25 - Battlefield Banner · PvE Prio
🎯 Read it by mode: if you are grinding PvE, prioritize the PvE-tagged breakpoints (Empyrean Lord Lv10, Battlefield Banner Lv25). For 1v1 PvP, chase Executing Blade (Lv10, Lv25). For everyday PvX, the Battlefield Banner / Doom Shield / Nezekan Shield / Comrade in Arms breakpoints carry the most value.
